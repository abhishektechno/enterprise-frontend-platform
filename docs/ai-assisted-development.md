# AI-Assisted Development Log

This project uses AI-assisted engineering tools as development aids.

AI-generated suggestions are reviewed, tested and modified before being
accepted.

## Tools

- OpenAI Codex
- Claude Code
- GitHub Copilot
- Cursor

## Uses

- Architecture review
- Code scaffolding
- Refactoring suggestions
- Test-case generation
- Debugging support
- Documentation review

## Principles

1. AI output is never accepted without review.
2. Generated code must pass TypeScript, linting and tests.
3. Architectural decisions remain human-owned.
4. Security-sensitive code receives manual review.
5. Significant AI-generated changes are documented.
